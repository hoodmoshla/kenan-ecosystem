# منظومة كنان — KenanWallet / عملة KEN (شبكة تجريبية)

**الحالة: شبكة تطوير وتجارب فقط. لا أموال حقيقية ولا شبكة رئيسية ولا إدراج ولا مراجعة أمنية إنتاجية.** راجع [docs/STATUS.md](docs/STATUS.md) للنتائج المثبتة والنواقص.

## الموجود حاليًا
- `blockchain/` — عقدة Python تجريبية أحادية، تحويلات Ed25519 موقعة، رسوم ثابتة، كتل مرتبطة بالتجزئة، وسجل أحداث يعاد منه بناء الأرصدة عند التشغيل. أحداث faucet موثقة ومحدودة لكل عنوان.
- `wallet-core/` — المحفظة المرجعية في Python؛ اشتقاق BIP39/Ed25519 فيها هو مرجع توافق Android.
- `android-app/` — تطبيق Kotlin/Compose باتجاه RTL: إنشاء/استعادة عبارة BIP39 من 24 كلمة، تشفيرها محليًا بـAES-GCM ومفتاح Android Keystore، عرض الرصيد الحي وQR للاستقبال، معاينة المستلم والمبلغ والرسوم، ثم توقيع محلي وإرسال إلى RPC الحالي والتحقق من المعاملة. البناء Debug فقط؛ لم يُختبر على محاكي أو جهاز فعلي.
- `rust-core/` — مكتبة صغيرة للتوقيع واشتقاق العناوين، وليست عقدة شبكة.
- `backend/` — API ووحدات تداول DEMO؛ أرصدة التداول تجريبية داخل الذاكرة ولا تُسوّى على السلسلة.
- `explorer/` وصفحة `/explorer` — عرض للقراءة فقط لشبكة Python التجريبية.
- الاختبارات: **23 اختبار Python**، و**4 اختبارات Android JVM** لـBIP39 والتوقيع والمبالغ والتوافق مع Python، و**اختبارا Rust**.

كل أرصدة KEN بيانات اختبار. عقدة Python ليست إجماعًا موزعًا ولا بنية مالية إنتاجية؛ لا تعرضها على شبكة عامة.

## تشغيل الشبكة التجريبية

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
python3 -m blockchain.node_server --port 8545 --data data/chain.json
KENAN_NODE_URL=http://127.0.0.1:8545 python3 -m backend.app --port 8000
python3 -m unittest discover -s tests -v
```

المستكشف: <http://127.0.0.1:8545/explorer> · تفاصيل الواجهات: [docs/API.md](docs/API.md)

## بناء Android واختباره

يتطلب Android SDK 34 وJDK 17 أو أحدث:

```bash
cd android-app
./gradlew --no-daemon :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

عنوان Debug الافتراضي `http://10.0.2.2:8545` ليتصل المحاكي بعقدة على المضيف. يمكن تغييره وقت البناء عبر `-PkenanNodeUrl=http://<عنوان-عقدة-التطوير>:8545`. يسمح HTTP في Debug فقط؛ لا تستخدم شبكة عامة أو غير موثوقة. تفاصيل التشغيل والأمان في [docs/ANDROID.md](docs/ANDROID.md).

## قواعد المشروع

- يقرأ التطبيق الرصيد من العقدة ولا يحتفظ بدفتر أرصدة محلي.
- لا تُرسل عبارة الاستعادة أو المفتاح إلى العقدة أو Backend؛ تستخدم العبارة محليًا بعد تشفيرها على الجهاز.
- لا يعلن التطبيق نجاح التحويل قبل قراءة هاش المعاملة وحقولها والتحقق منها عبر RPC.
- أرصدة التداول DEMO منفصلة عن KEN على السلسلة، والجسر معطّل.
